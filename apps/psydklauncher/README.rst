Psydk Launcher
==============

This is the Psydk launcher app for iOS (and in the future, Android). It wraps the `psydk_launcher` Python package, which is a command line tool for launching Psydk experiments.

iOS is a very closed platform, so this app bundles all the Python dependencies needed to run Psydk experiments. At the moment, this includes:

- `psydk`
- `numpy`
- `pandas`
- `matplotlib`
